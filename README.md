# 🔢 MNIST Digit Classification using CNN

## 📌 Project Overview

本專案使用 **Convolutional Neural Network（CNN）** 建立 MNIST 手寫數字影像分類模型，完成 0～9 數字辨識與模型評估。

## 🛠 Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- TensorFlow
- Keras

## 📈 Result

使用 CNN 進行 MNIST 手寫數字分類，並透過 Test Accuracy、Training / Validation 曲線與分類結果分析模型表現。
